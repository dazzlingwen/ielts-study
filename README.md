# 栖岸 IELTS

雅思自学训练工作台。纯前端、零后端依赖，所有练习数据保存在浏览器本地，可导出 JSON 备份。

## 功能模块

| 模块 | 能力 |
|---|---|
| 今日训练 | 每日任务清单、倒计时、计划/专注/连续天数统计、考试目标设置 |
| 听力 | TTS 朗读原创脚本、整段/逐句播放、语速调节、逐句听写核对、进度记录 |
| 阅读 | 原创学术文章、判断题 + 填空题作答、自动判分、逐题解析、生词联动词库 |
| 词汇 | 翻卡复习、今日队列、自定义词库 |
| 写作 | Task 2 题目轮换、每题独立草稿、词数统计、四项自查、导出 txt |
| 真题 | 套卷成绩登记（自动同步模考台账）、复盘备注、内置模拟套卷训练入口 |
| 模考记录 | 通用成绩台账、雅思总分换算（0.5 取整）、CSV 导出 |

## 快速开始

```bash
npm install     # 安装构建依赖
npm run dev     # 本地开发（默认 http://localhost:5173）
npm run build   # 构建到 dist/（相对路径，可任意子目录部署）
npm run preview # 预览构建产物
```

## 目录结构

```
ielts-study/
├── index.html            # 入口
├── vite.config.js        # 构建配置（base 相对路径）
├── src/
│   ├── main.js           # 组装入口：标签路由 + 模块挂载
│   ├── ui.js             # DOM 助手、toast、tab 路由
│   ├── core/
│   │   ├── store.js      # 状态管理 + localStorage 持久化（未来换云库只改这里）
│   │   ├── data.js       # 种子数据：原创听力/阅读材料、模拟套卷
│   │   └── utils.js      # 日期、ID、下载、雅思总分换算
│   ├── modules/          # 七个功能模块，每个一个文件
│   └── styles/           # tokens.css（令牌）+ app.css（应用样式）
└── dist/                 # 构建产物（git 忽略）
```

## 关键约定

- **版权红线**：内置材料全部为原创模拟内容，不内置剑桥雅思真题原文。真题模块只做成绩登记与复盘框架。
- **数据层**：一切读写经过 `store.js`；迁移云数据库（Supabase / 云开发）时替换其实现即可。
- **音频**：MVP 用 Web Speech API。生产环境替换为授权音频时，只需改 `modules/listening.js` 的 `speak()`。
- **无虚构数据**：不内置提分承诺、用户评价；总分换算只用用户自己录入的分数。
